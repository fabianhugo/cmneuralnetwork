4Send it to the Calliopes

Plug the sender board into this computer with a USB cable, press Connect, then Send the brain. It passes everything on to the other boards by radio — nobody has to change any code.

What do the answers mean?

Give each answer a name. The Calliope shows it on its screen when that answer wins, so "frech" is more fun than "1".

Which Calliope is which neuron

Press B on each board and it prints its own number to the USB log. Paste that number here so the sender knows which board should become which neuron. Keep the minus sign if there is one.
